# Soumitaa's Birthday Surprise

## Run locally
Open the folder in VS Code, install the "Live Server" extension, right-click `index.html` → "Open with Live Server". Or just open `index.html` directly in Google Chrome.

## Replace photos
Put real photos in `assets/photos/` named `photo-1.jpg` ... `photo-5.jpg`. Edit captions in `script.js` → `photos` array.

## Change message/letter
Edit `letterLines` array in `script.js` and the messages in `index.html`.

## Replace illustrations / music
Replace SVGs in `assets/images/`. Add `birthday-music.mp3` to `assets/audio/`. Music is off by default.

## Deploy
Push to GitHub and enable GitHub Pages, or import the repo into Vercel.
